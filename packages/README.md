# packages/

Hier landen später eigene Arch-Pakete (je ein Unterordner mit `PKGBUILD`),
zum Beispiel `kairo-branding` oder `kairo-dotfiles`.

**In Phase 1 leer.** Das Branding der Live-ISO liegt vorerst direkt im
Archiso-Overlay unter `iso/airootfs/`. Sobald ein installiertes Kairo-System
dasselbe Branding braucht, wird es in ein Paket `kairo-branding` umgezogen.
