# Kairo OS 1.0.1

Diese Version bleibt bei `linux-zen` als Standardkernel. `linux-kairo` ist
noch kein Bestandteil dieser Freigabe.

- Vor dem Löschen wird die ausgewählte SSD erneut anhand ihrer Identität
  geprüft. Modell, Seriennummer und Größe erscheinen im Installer.
- Belegte Laufwerke werden abgelehnt. Verschlüsselung ist vorausgewählt;
  Abbrechen startet keine unverschlüsselte Installation.
- Das installierte System verwendet eine Firewall für IPv4 und IPv6.
  Antworten auf ausgehende Verbindungen bleiben erlaubt; selbst gehostete
  Dienste benötigen gezielte Freigaben.
- Die native ChatGPT-Installation verwendet den festgelegten öffentlichen
  Signaturschlüssel und das signierte Paket-Repository.
- Automatische Tests bedienen den echten Verschlüsselungsdialog mit
  deutscher Tastaturbelegung, ohne Schlüsseldatei im Initramfs.

Veröffentlichen nur nach allen grünen Prüfungen des Release-Commits.
Hardwaretests auf dem Ryzen 5 4500 mit RX 6500 XT sind getrennt in
[`STATUS.md`](../../STATUS.md) nachzuweisen.

**Installation löscht die gesamte ausgewählte SSD.** Die Windows-SSD vorher
abstecken. Anleitung: [`docs/06-installieren.md`](../06-installieren.md).
