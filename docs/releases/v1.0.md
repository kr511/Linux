## Kairo OS 1.0

Eine eigene Linux-Distribution auf Basis von Arch Linux: GNOME im
Kairo-Design, fertig zum Spielen und eingestellt für AMD-Grafik.

### Was drin ist

- **Grafischer Installer**: Festplatte wählen, Benutzer anlegen, fertig
- **Snapshots**: vor jedem Update automatisch, mit **Kairo Wiederherstellen**
  zurück zum alten Stand (geht auch vom USB-Stick)
- **Verschlüsselung** auf Wunsch (Passwort beim Start, deutsche Tastatur)
- **Kairo Update**: Updates mit einem Klick, tägliche Erinnerung
- **Spiele**: Steam mit Proton, Roblox (Sober), GameMode, MangoHud, Gamescope
- **Apps**: Firefox, Discord, Spotify, VS Code, Claude und ChatGPT als
  Web-Apps, Claude Code und Codex im Terminal
- **AMD**: Kernel `linux-zen`, Mesa/Vulkan auch in 32 Bit, FreeSync an
- **Willkommen bei Kairo**: kurze Starthilfe nach dem ersten Anmelden
- **Hardware prüfen** im Live-System: passt mein PC?

### Download und Installation

1. Unten bei **Assets** die `.iso` herunterladen.
2. Prüfsumme vergleichen (`SHA256SUMS`), unter Windows in PowerShell:
   `Get-FileHash .\kairo-*.iso`
3. Mit [Rufus](https://rufus.ie) im **DD-Modus** auf einen USB-Stick
   (mindestens 4 GB) schreiben.
4. Im BIOS **Secure Boot ausschalten**, vom Stick starten.
5. Erst **Hardware prüfen**, dann **Kairo installieren**.

Ausführlich: [docs/06-installieren.md](https://github.com/kr511/Linux/blob/main/docs/06-installieren.md)

> **Achtung:** Der Installer löscht die ganze ausgewählte Festplatte.

### Getestet

Jede Version wird vor dem Veröffentlichen automatisch gebaut und in einer
virtuellen Maschine geprüft: Live-System mit UEFI und BIOS, Installation
mit und ohne Verschlüsselung, erster Start, Zurückrollen. Details:
[STATUS.md](https://github.com/kr511/Linux/blob/main/STATUS.md)

### Bekannte Grenzen

- Secure Boot wird nicht unterstützt (wie bei Arch Linux).
- Für NVIDIA-Grafikkarten fehlt der NVIDIA-Treiber, Kairo ist auf AMD eingestellt.
- Roblox läuft über Sober, nicht jedes Spiel funktioniert.
- Dual-Boot neben Windows ist noch nicht möglich.
